# CS771: Introduction to Machine Learning

## Repository Overview: SVMs, Generative Models & EM

This repository contains three core machine learning projects developed for the CS771: Introduction to Machine Learning coursework at IIT Kanpur for the 2025–26 academic session. The projects provide robust implementations across key algorithmic paradigms, specifically focusing on supervised classification, probabilistic generative modelling, and unsupervised mixture regression.

### Documentation & Methodology

To ensure rigorous academic standards, each assignment is accompanied by a formal NeurIPS-style report compiled in LaTeX. These reports comprehensively document the theoretical and empirical aspects of the work, featuring:
* Step-by-step mathematical derivations.
* Detailed experimental results.
* In-depth technical analysis.
